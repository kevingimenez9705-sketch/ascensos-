# Recortes de cara

Versiones cuadradas (320×320) de las fotos de `assets/photos/`, centradas en
la cara. El Campus las usa en los avatares; si falta un recorte, usa la foto
original.

Al agregar o cambiar una foto, generá su recorte con cualquier editor
(cuadrado, cara centrada, fondo blanco) y guardalo acá con el mismo nombre en
`.jpg`, o pedile a Claude que los regenere.
