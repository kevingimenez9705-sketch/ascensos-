# Assets: logos y fotos

Convención de nombres de archivo. Mientras un archivo no exista, la app
muestra automáticamente un círculo/cuadrado de iniciales — no hace falta
tocar código ni `data.js`, solo subir la imagen con el nombre exacto
(en `.jpg` o `.png`, cualquiera de los dos funciona).

## Logos de marca (`assets/logos/`)

| Marca | Archivo esperado |
|---|---|
| Hamburguesas Extremas | `assets/logos/hex.jpg` (o `.png`) |
| Sabores Express | `assets/logos/sabores.jpg` (o `.png`) |

## Fotos de personas (`assets/photos/`)

Un archivo por persona, nombrado `<marca>-<nombre-en-slug>.jpg`.
